# Дифференцируемый Fisher LDA в JAX: от generalized `eigh` до ML-примера

[English](generalized-eigh-lda.md) · [Русский](generalized-eigh-lda-ru.md)

Я добавил в JAX поддержку обобщённых эрмитовых задач на собственные значения: сначала [тип 1](https://github.com/jax-ml/jax/pull/41162), затем [типы 2 и 3](https://github.com/jax-ml/jax/pull/41197). Оба PR приняты. Здесь я покажу одно применение типа 1: регуляризованный Fisher LDA, где я могу дифференцировать спектральный критерий по регуляризации и преобразованию признаков.

Я собрал [исполняемый пример](../examples/differentiable_lda.py), независимый расчёт через NumPy и SciPy, проверки `jit`, `vmap` и градиентов. Для разбора самой реализации `eigh`, преобразований собственных векторов и трёх типов задачи я подготовил [отдельную заметку](../case-studies/generalized-eigh.md).

## Какую задачу я решаю

Я сгенерировал 120 объектов: три класса, по 40 объектов в каждом, с тремя признаками. Третий признак содержит большую дисперсию шума, но не разделяет средние классов. На таком примере удобно сравнить PCA, учитывающий общую дисперсию, с LDA, использующим метки.

![PCA и регуляризованный Fisher LDA на одних синтетических данных](assets/fisher-lda.png)

Я построил обе проекции на тех же данных, без тестовой выборки. Этот рисунок иллюстрирует различие критериев; я не измеряю качество классификации или обобщение на новых объектах. [SVG для слайдов](assets/fisher-lda.svg).

Для каждого класса я рассчитываю среднее $\mu_c$, число объектов $n_c$ и общее среднее $\mu$. Затем строю две матрицы:

$$
S_W = \frac{1}{N}\sum_c\sum_{i:y_i=c}(x_i-\mu_c)(x_i-\mu_c)^T,
\qquad
S_B = \frac{1}{N}\sum_c n_c(\mu_c-\mu)(\mu_c-\mu)^T.
$$

Я ищу направления, в которых разброс между классами велик относительно разброса внутри классов. Такой подход к supervised dimensionality reduction описан в [документации scikit-learn](https://scikit-learn.org/stable/modules/lda_qda.html). Межклассовая матрица имеет ранг не больше $C-1$, поэтому для трёх классов я оставляю две ведущие компоненты.

Чтобы получить положительно определённую метрику, я добавляю ridge-регуляризацию:

$$
B = S_W + \alpha I,\qquad \alpha > 0.
$$

Я максимизирую отношение Рэлея $v^T S_B v / v^T B v$. Условие стационарности приводит к обобщённой задаче типа 1:

$$
S_B v = \lambda Bv.
$$

В примере ядро вычисления выглядит так:

```python
within, between = scatter_matrices(x, labels)
metric = within + ridge * jnp.eye(x.shape[1], dtype=x.dtype)
values, vectors = jax.scipy.linalg.eigh(between, metric, type=1)
projection = (x - x.mean(axis=0)) @ vectors[:, -2:]
```

Я беру последние два столбца, поскольку `eigh` возвращает собственные значения по возрастанию. Для рисунка я дополнительно меняю порядок компонент, чтобы первой шла компонента с наибольшим значением.

## Почему я использую обобщённую задачу

Формально можно умножить уравнение на $B^{-1}$. Но $B^{-1}S_B$ обычно не симметрична: симметрия двух исходных матриц этого не гарантирует. Поэтому вызов обычного эрмитова `eigh` для такого произведения меняет задачу.

В реализации я свожу задачу через разложение Холецкого $B=LL^T$ к симметричной матрице $L^{-1}S_BL^{-T}$, используя треугольные решения. После решения обычной задачи возвращаю векторы в исходные координаты через $L^{-T}$. Подробности этого изменения я разобрал в [заметке об upstream-вкладе](../case-studies/generalized-eigh.md).

Из этого же преобразования следует нормировка:

$$
V^T B V = I.
$$

Я проверяю именно эту нормировку, а не $V^TV=I$. Для независимого эталона я использую [`scipy.linalg.eigh`](https://docs.scipy.org/doc/scipy/reference/generated/scipy.linalg.eigh.html), у которого тип 1 задаёт то же уравнение и ту же метрику нормировки. Собственные векторы я не сравниваю поэлементно: их знаки могут различаться. Вместо этого проверяю уравнение и нормировку.

## Что я дифференцирую

Я ввожу два параметра: $\theta=\log\alpha$ и $\phi=\log s$, где $s$ — масштаб первого признака. Через $\exp$ я сохраняю положительность регуляризации и масштаба. При изменении признака заново рассчитываю обе матрицы, $S_W$ и $S_B$.

Для демонстрации я выбираю скалярный спектральный критерий:

$$
J(\theta,\phi) = \sum_{k\in\text{две ведущие компоненты}}
\log(1+\lambda_k(\theta,\phi)).
$$

Я вычисляю его значение и градиент через `jax.jit(jax.value_and_grad(score))`. Затем независимо рассчитываю центральные конечные разности: собственные значения получаю через SciPy, а матрицы разброса — через NumPy с отдельным циклом по классам. Так я проверяю производную по регуляризации и производную через обе матрицы.

Я использую $J$ как учебный пример дифференцируемого спектрального вычисления. Я не предлагаю выбирать по нему гиперпараметры для реальной задачи без проверки на отложенных данных.

## Что я запустил

Я проверил eager- и JIT-решение, `jit(vmap(...))` для трёх значений регуляризации, собственные значения относительно SciPy, уравнение задачи, нормировку и оба компонента градиента. Локально я выполнил запуски на Windows CPU, Python 3.12.10, jaxlib 0.11.2, NumPy 2.5.3 и SciPy 1.18.1. Для JAX я использовал исходники ревизии `15998e8040d07995ac5dcc4643333e1b88e8c047`.

| Точность | Максимальный относительный остаток уравнения | Максимальное абсолютное расхождение градиента с конечными разностями SciPy |
| --- | --- | --- |
| `float32` | $1.43\cdot10^{-7}$ | $5.43\cdot10^{-7}$ |
| `float64` | $2.54\cdot10^{-16}$ | $2.49\cdot10^{-11}$ |

Остаток я считаю как $\|S_BV-BV\Lambda\|_F/(\|S_BV\|_F+\|BV\Lambda\|_F)$. В таблице я беру максимум по eager- и JIT-запускам. Для конечных разностей я использую шаг $10^{-5}$; это численный эталон с собственной погрешностью, а не точная производная. Полный вывод я сохранил для [x64 off](../validation/differentiable-lda-x32.json) и [x64 on](../validation/differentiable-lda-x64.json).

В CI я включил те же проверки и генерацию рисунка; результаты запусков доступны в [GitHub Actions](https://github.com/jabrailkhalil/jax-reliability-notes/actions/workflows/reproduce.yml). Я не выполнял этот пример на GPU или TPU. В синтетическом наборе собственные значения разделены; я не исследую здесь производные собственных векторов при кратных значениях или поведение на плохо обусловленных матрицах. Код рассчитан на эту трёхклассовую лабораторную работу, а не на универсальный LDA-классификатор.

## Как я воспроизвожу пример

Я фиксирую исходники JAX, потому что приведённый пример использует уже принятые изменения, а дата merge сама по себе не означает их наличие в установленном релизе.

```sh
git clone https://github.com/jabrailkhalil/jax-reliability-notes.git
cd jax-reliability-notes
python -m venv .venv
```

Я активирую окружение через `source .venv/bin/activate` на Linux/macOS или `.\.venv\Scripts\Activate.ps1` в PowerShell. Затем выполняю:

```sh
git clone --filter=blob:none https://github.com/jax-ml/jax.git .lab/generalized-jax
git -C .lab/generalized-jax checkout 15998e8040d07995ac5dcc4643333e1b88e8c047
python -m pip install -r requirements-lda.txt .lab/generalized-jax
python examples/differentiable_lda.py
python examples/differentiable_lda.py --x64 --plot-dir articles/assets
```

Я использую Python 3.12. Скрипт печатает измерения и версии зависимостей, а при расхождении с эталоном завершает работу с ошибкой.
